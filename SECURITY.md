# Security & Authorized Use Policy

## Authorized Use Only
ARTEX-Nexus and its integrated `BaaRai/ARTEX` submodule are built strictly for:
- Authorized penetration testing and bug bounty programs within declared scope
- Owned infrastructure, isolated labs, and defensive security research
- White-box code review, patch-diff analysis, and vulnerability remediation

Never run active security testing against systems without explicit written authorization. Always configure and enforce `scope-guard-mcp` before testing.

## Reporting Security Issues in ARTEX-Nexus
If you discover a security vulnerability in any MCP server or pipeline script in this repository, please open a private GitHub Security Advisory on this repository rather than a public issue.
